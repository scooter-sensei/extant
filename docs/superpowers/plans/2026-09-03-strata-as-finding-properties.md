# Strata as a Finding Property Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Label every finding with the kind of document it came from, so a
first run reports 4,431 findings in ordinary documents instead of 54,790
across vendored trees, per-release snapshots, changelogs and generated
references.

**Architecture:** One new leaf module, `extant/strata.py`, that maps a path
(and optionally a body) to one of five stratum names. `Located` gains a
`stratum` field set at its four construction sites, which already know the
path. `Finding` is not touched, so the baseline fingerprint is unaffected and
no rule imports anything.

**Tech Stack:** Python 3.9 floor, standard library only, no third-party runtime
dependencies. pytest for tests.

## Global Constraints

Copied verbatim from `AGENTS.md` and `tests/test_module_quality.py`. Every task
must satisfy all of them.

- **ASCII only, everywhere, including prose and comments.** Non-ASCII raises
  `UnicodeEncodeError` on a cp437 console and kills the process. Use `-`,
  `...`, `->`, plain quotes.
- **`from __future__ import annotations` at the top of every module.** It is
  what keeps `X | Y` annotations legal on the 3.9 floor.
- **900 lines per module, 303 per function.** `sites.py` is currently 451
  lines; `strata.py` must stay far below the ceiling.
- **Every shipped module declares `__all__`.**
- **Narrow exception handlers.** A broad catch is allowed only when it reports
  what it caught.
- **Never commit without being asked** - but this plan's author has been asked,
  so each task ends in a commit on the current branch.
- **No `Co-Authored-By` trailer.** A `commit-msg` hook rejects it.
- **`plugin/skills/extant/payload/` IS the shipped artifact.** Editing the tool
  means editing files under `payload/`.

from extant.strata import ORDER, classify


@pytest.mark.parametrize("path, expected", [
    ("node_modules/left-pad/README.md", "vendored"),
    ("third_party/py/mock/docs/index.md", "vendored"),
    ("docs/versions/8.6.0/reference/cli.mdx", "version-snapshot"),

```python
"""What kind of document a finding came from.

Measured on 50 pinned public repositories: a sweep prints 54,790 findings and
4,431 of them are in ordinary documents. The other 92 per cent are in trees a
reader would not call documentation-with-claims - per-release snapshots,
changelogs, machine-written allowlists, vendored code and generated API
references.

`exclude_paths` already exists and does not close that gap. Three
configuration passes over the same corpus moved the headline by under one per
cent, and `install.py` refuses 35 of the 50 repositories unaided. Whether a
tree is vendored or a per-release snapshot is visible FROM THE REPOSITORY, so
it should not have to be configured.

LABELS, NOT EXCLUSIONS. Excluding hides; a stratum labels. A rule that goes
quiet because a tree was excluded is indistinguishable from a rule that broke,
which is the ambiguity the denominator exists to remove. Both mechanisms stay
and they answer different questions.

This module imports nothing from the package - it takes a string and returns a
string - so it cannot be half of an import cycle, and no rule needs to know it
exists.
"""
from __future__ import annotations

import re

__all__ = ["ORDER", "classify"]

# Precedence. First match wins, which is what makes the strata a PARTITION
# rather than overlapping buckets that sum to more than the total: bazel's
# `docs/versions/8.6.0/reference/` is generated AND snapshotted, and a fixed
# order is the only thing that stops it being counted twice.
ORDER = ("vendored", "version-snapshot", "generated", "historical-record",
         "ordinary")

# Somebody else's code, checked in. Counting findings here reports the state of
# another project through this one. 4,175 findings on the measured corpus.
_VENDORED = re.compile(
    r"(^|/)(node_modules|vendor|third_party|thirdparty|\.venv|venv|"
    r"site-packages|bower_components|Godeps|_vendor|vendored)(/|$)",
    re.IGNORECASE)

# Documentation kept as one directory per release. `bazelbuild/bazel` holds 12
# such directories, each a copy of the same tree, so one dead link written once
# is counted twelve times - 39,698 findings, 72.5 per cent of the corpus total.
_VERSION_SNAPSHOT = re.compile(
    r"(^|/)(?:versioned_docs/version-[^/]+|versions?/v?\d+[\w.]*|"
    r"v\d+(?:\.\d+)*)(/|$)", re.IGNORECASE)

# Machine-written documentation. Whether extant SHOULD flag it is a real
# question; it gets its own label rather than being folded into the headline.
_GENERATED_PATH = re.compile(
    r"(^|/)(api|apis|reference|generated|_generated|autogen|autogenerated|"
    r"_build|_site|dist|build)(/|$)", re.IGNORECASE)

# The one content test, and it is confined to `generated` deliberately: a
# generated file that says so is the only kind identifiable without guessing
# at intent.
_GENERATED_MARKER = re.compile(
    r"(do not edit|don't edit|autogenerated|auto-generated|"
    r"generated by|this file is generated|@generated)", re.IGNORECASE)

# A HISTORICAL RECORD IS NOT A LIVE CLAIM. A changelog entry naming a file that
# has since moved is an accurate record of what was true at that release, not a
# claim that rotted. `angular/packages/zone.js/CHANGELOG.md` supplies 391
# findings alone and four of node's `doc/changelogs/CHANGELOG_V*.md` supply 468
# between them. An allowlist is a machine-maintained list of test-case paths in
# an EXTERNAL suite and was never a document link at all: babel's two supply
# 343.
_HISTORICAL = re.compile(
    r"(^|/)(CHANGELOG|CHANGES|HISTORY|NEWS|RELEASES?|RELEASE[-_]NOTES|"
    r"[\w.-]*allowlist|[\w.-]*denylist|[\w.-]*blocklist|[\w.-]*whitelist)"
    r"[\w.-]*\.(md|mdx)$", re.IGNORECASE)

# How much of a document to read for the generated marker. A generator that
# announces itself does so at the top; reading further would cost the sweep
# real time on a large corpus for no measured gain.
_MARKER_WINDOW = 4000


def classify(path: str, body: str = "") -> str:
    """Which stratum this document belongs to. Exactly one, always."""
    if _VENDORED.search(path):
        return "vendored"
    if _VERSION_SNAPSHOT.search(path):
        return "version-snapshot"
    if _GENERATED_PATH.search(path):
        return "generated"
    if body and _GENERATED_MARKER.search(body[:_MARKER_WINDOW]):
        return "generated"
    if _HISTORICAL.search(path):
        return "historical-record"
    return "ordinary"
```

```python
def summarise_strata(items: list[Located]) -> list[str]:
    """The per-stratum breakdown, or nothing when it would say nothing.

    Measured on 50 repositories: a sweep reports 54,790 findings and 4,431 of
    them are in ordinary documents. Printing only the first number is the
    misleading count this whole change exists to remove - so the ordinary
    figure leads and the rest is broken out and labelled, never hidden.

    Returns lines rather than printing, so the caller keeps ownership of `out`
    and the whole thing is testable without capturing stdout.
    """
    counts: dict[str, int] = {}
    for item in items:
        counts[item.stratum] = counts.get(item.stratum, 0) + 1
    ordinary = counts.get("ordinary", 0)
    elsewhere = sum(n for name, n in counts.items() if name != "ordinary")
    if not elsewhere:
        return []
    lines = [f"  {ordinary} in ordinary documents; {elsewhere} elsewhere:"]
    for name in strata.ORDER:
        if name != "ordinary" and counts.get(name):
            lines.append(f"    {counts[name]}  {name}")
    return lines
```

    If two patterns can both claim a path and the precedence is wrong, the
    per-stratum counts stop summing to the total - and a table that does not

        "docs/versions/8.6.0/reference/cli.mdx",
        "docs/api/client.md",
        "CHANGELOG.md",

        "third_party/x/CHANGELOG.md",
        "versioned_docs/version-3.1/api/index.md",
    ]
    items = [Located(p, Finding(1, "k", "d"), primary=False,
                     stratum=classify(p)) for p in paths]
    counts = {name: sum(1 for i in items if i.stratum == name)
              for name in ORDER}
    assert sum(counts.values()) == len(items)
    assert set(counts) == set(ORDER)
